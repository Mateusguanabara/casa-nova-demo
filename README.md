# 🏡 Casa Nova | Projeto Demonstrativo

Site de Chá de Casa desenvolvido para proporcionar uma experiência digital elegante, interativa e responsiva.

🔗 **[Visualizar projeto online](https://mateusguanabara.github.io/casa-nova-demo/)**

## ✨ Funcionalidades

- Layout moderno e responsivo para celulares e computadores.
- Contagem regressiva dinâmica para o evento.
- Catálogo de presentes com pesquisa em tempo real.
- Animações suaves durante a navegação.
- Seção de agradecimento personalizada.
- Versão demonstrativa com reservas desativadas.

## 🛠️ Tecnologias utilizadas

- HTML5 — Estrutura do site.
- CSS3 — Estilização e responsividade.
- JavaScript — Interatividade e funcionalidades.

## 🎯 Objetivo

Demonstrar minhas habilidades no desenvolvimento de experiências web personalizadas, com foco em design, usabilidade e responsividade.

**Observação:** Este projeto é uma versão demonstrativa. A funcionalidade de reserva de presentes está desativada.
